# AgentDeck 2.0 — службы и гости

Согласовано с владельцем 27.10.2026.

## Что входит

**1. Службы — для всех.** Программа, которая должна жить без открытого терминала
(Tailscale, сервер сайта, бот), становится службой: файл `.services/<имя>.sh`, сторож её
запускает, поднимает после падения и останавливает со всеми дочерними процессами.
- сторож — в каждой установке AgentDeck, на сервере и в Docker;
- `/services` в Телеграм-боте: список служб и кнопки «перезапустить / остановить / запустить»;
- блок «Службы» на панели: состояние, журнал, те же кнопки;
- правило для агентов: долгоживущее — только службой, и сказать об этом человеку.

**2. Гости — модуль, по умолчанию выключен.** Другие люди работают на вашем сервере,
каждый в своей песочнице, на вашей подписке с дневным лимитом, через один общий бот.
- **приглашения:** человек пишет гостевому боту `/start` → вам «Маша хочет доступ. Пустить?»
  с кнопками → песочница создаётся сама, человек получает адрес и пароль;
- **мастер «Гости» на панели:** включение по шагам с проверкой каждого (Docker, бот, домен);
  список гостей, расход за день, лимит, «выключить» и «удалить» — кнопками;
- **вопрос при установке:** «Будут ли работать другие люди?», по умолчанию «нет»; задаётся,
  только если перед установщиком человек; включить можно в любой момент позже;
- модуль переезжает в репозиторий AgentDeck папкой `guests/`; команда остаётся для автоматизации.

**3. Исправления, которые уже готовы:** в Docker появился «уборщик» процессов, и мёртвый
Claude больше не держит терминал (dev a510473); порядок терминалов не прыгает (1.9.0).

**4. Страница на GitHub:** раздел «Что нового в 2.0» с описанием служб и гостей и
скриншотами — панель со службами, мастер гостей, `/services` и приглашение в Телеграме.
Скриншоты — на демо-установке с выдуманными данными, не с настоящих песочниц.

**5. Выпуск:** все тесты, установка на чистом сервере (проверка на GitHub), журнал
изменений, тег v2.0.0.

## Порядок работ

1. Приглашения через бот (самое полезное в жизни; механизм уже есть).
2. Службы в ядро: сторож в установке на сервере и в Docker, правило для агентов.
3. `/services` в боте владельца.
4. Панель: блок «Службы» и мастер «Гости».
5. Вопрос при установке.
6. Перенос модуля `guests/` в репозиторий.
7. Страница на GitHub и скриншоты.
8. Выпуск 2.0.
